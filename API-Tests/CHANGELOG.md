# История изменений API-тестов

## [2.0.0] - 2024

### Добавлено

#### Централизованные фикстуры
- Создана система фабрик тестовых данных в `API-Tests/fixtures/`
- Фикстуры для `debtImporter`, `debtCollection`, `dcCourt`
- Типы для построителей (`FixtureBuilder`)
- Централизованный экспорт через `fixtures/index.ts`

#### Централизованные утилиты
- `base-test-utils.ts` - базовый класс с методами валидации
- `assertions.ts` - доменно-специфичные ассерты для пакетов, судов, импортеров
- `allure-config.ts` - конфигурация Allure
- `boundary-values.ts` - генерация граничных значений
- Централизованный экспорт через `test-utils/index.ts`

#### Конфигурация
- `playwright.config.ts` - конфигурация Playwright для API-тестов
- `config/apiConfig.ts` - типизированная конфигурация API
- `tsconfig.api.json` - обновлен с путями для новых модулей

#### Улучшенные сервисы
- `debtImporterService.ts` - теперь использует фикстуры
- `debtCollectionService.ts` - теперь использует фикстуры
- `dcCourtService.ts` - теперь использует фикстуры

#### Документация

- `README.md` - инструкции по использованию
- `CHANGELOG.md` - этот файл

### Изменено

- Обновлены `package.json` скрипты для использования `playwright.config.ts`
- Обновлены скрипты генерации отчетов
- Добавлены скрипты для запуска тестов по сервисам

### Улучшения

- **DRY принцип** - устранено дублирование кода (400+ строк)
- **Унификация** - одинаковый подход ко всем тестам
- **Типизация** - TypeScript поддержка для всех фикстур
- **Читаемость** - тесты становятся чище и понятнее
- **Поддержка** - легко менять тестовые данные в одном месте

### Миграция

Для миграции существующих тестов:

1. Замените inline-объекты на фикстуры
2. Используйте `BaseTestUtils` вместо локальных утилит
3. Обновите Allure декораторы
4. Импортируйте конфигурацию через `apiConfig`

### Планируется

- Миграция всех существующих тестов
- Автоматизация миграции тестовых данных
- Добавление новых фикстур для других сервисов
- Интеграция с CI/CD
